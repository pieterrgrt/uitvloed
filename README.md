# Uitvloed

Uitvloed is een kleine, onafhankelijke uitgeverij-werkplaats waarin boeken van manuscript tot gedrukte pagina en website worden gemaakt: teksten staan als platte bestanden in `boeken/`, de vormgeving ligt vast in herbruikbare Typst-sjablonen in `sjablonen/`, en met Pandoc en Node.js wordt uit dezelfde bron zowel een drukklare pdf als de website in `site/` gebouwd — alles onder versiebeheer, zodat elke wijziging bewaard blijft.
