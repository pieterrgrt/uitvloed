# Proeven

Eerste proeven van de boeken in `boeken/`, om te downloaden en te lezen. Dit zijn bouwresultaten:
ze worden niet bijgewerkt als de tekst verandert. Maak nieuwe met `python3 gereedschap/bouw.py boeken/<titel>`
(die schrijft naar `boeken/<titel>/uit/`). Haal deze map weg voordat de branch wordt samengevoegd.
